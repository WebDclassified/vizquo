Optional AI

AI that explains design — on your terms

AI is off by default and never required. When you turn it on, you choose exactly where it runs — and nothing is sent until you confirm what's going.

Cloud · bring your own key

OpenRouter

Free :free models by default. Paste your own API key in Settings → AI (free to create at openrouter.ai) — or none at all if you prefer local.

  • Best for: quick answers with zero setup on your machine
  • Cost: free models by default; you control the key
  • Your key stays in your browser — used only by the extension
Local · no key, no cloud

Ollama

Runs entirely on your machine via the free Ollama app — the strictest privacy option. Nothing ever leaves your computer.

  • Best for: maximum privacy and fully offline AI
  • Cost: zero — no key, no account, no cloud
  • Setup: install Ollama, pull a model (e.g. llama3.2), pick it in Settings
  • ✓ "Why?" explanations — understand any element's look in plain language
  • ✓ Design-system summaries — a readable tour of the page's visual language
  • ✓ Diff narration — plain-English reports of how a design changed over time
  • ✓ Audit-fix priorities — AI ranks accessibility findings by impact
🛡️ Consent first: before the first request, Vizquo shows exactly what will be sent and requires your confirmation. Payloads are bounded and redacted (text ≤ 200 chars, sanitized HTML snippets) — input values and data attributes are never sent.

Setup guide

Your browser, step by step

After the download finishes, you're three small actions from using Vizquo.

1 Download ZIP → 2 Unzip the folder → 3 Load it in your browser
Google Chrome
  1. Download the Chrome ZIP and unzip it (right-click → Extract All). You get a folder named vizquo-0.10.1-chrome.
  2. Open chrome://extensions.
  3. Enable Developer mode (toggle, top-right).
  4. Click Load unpacked → select the unzipped folder.
  5. Pin Vizquo to the toolbar, open the side panel, and grant access to a page when prompted — done.
⚠️ Chrome shows a "Disable developer mode extensions" warning for manual installs — expected and safe. One-click installs arrive with the Web Store listing.
Microsoft Edge
  1. Download the Chrome ZIP (same package works) and unzip it.
  2. Open edge://extensions.
  3. Enable Developer mode (left sidebar toggle).
  4. Click Load unpacked → select the unzipped folder.
  5. Pin Vizquo, open the side panel, grant access — done.
Brave / Opera / Vivaldi (other Chromium)
  1. Download the Chrome ZIP and unzip it.
  2. Open your browser's extensions page: brave://extensions · opera://extensions · vivaldi://extensions.
  3. Enable Developer mode.
  4. Click Load unpacked → select the unzipped folder.
  5. Pin Vizquo and grant access — done.
Firefox
  1. Download the Firefox ZIP and unzip it.
  2. Open about:debugging#/runtime/this-firefox in Firefox.
  3. Click Load Temporary Add-on… and select the manifest.json inside the unzipped folder.
  4. Pin Vizquo and grant access — done.
⚠️ Temporary add-ons reset when Firefox restarts — re-load it to keep using Vizquo. A permanent, one-click install comes with the AMO listing.
Safari (coming soon)

Safari support needs a native macOS build (Apple's Xcode converter) plus the Apple Developer Program — it's on the roadmap.

👉 Vote for Safari support and you'll be notified when it ships. Meanwhile, use Chrome, Edge, or Firefox on macOS — Vizquo works identically there.

FAQ

Questions, answered

Everything users ask before installing.

Is Vizquo really free?

Yes. Every feature except AI is 100% free and local — no account, no ads, no data collection. AI is optional: the cloud option uses free models by default (you can bring your own key), and the local option (Ollama) costs nothing at all.

Is my data private?

Completely local by default. Scans, screenshots, and your library live only in your browser (IndexedDB). Vizquo makes zero network requests until you explicitly turn on AI — the UI loads no fonts, scripts, or analytics from anywhere. Site access is granted per-site, on demand.

How do I use the AI?

1. Open Vizquo → Settings → AI → enable it.

2. Choose a provider: OpenRouter (paste your own free API key) or Ollama (local, no key — install the free Ollama app and pull a model like llama3.2).

3. Use the AI buttons: "Why?" on any locked element, "Explain the design system", "Narrate the diff", or "Prioritize fixes".

4. Before the first request, Vizquo shows exactly what will be sent — confirm, and you're set.

Why do I need my own AI key? Can't you bundle one?

Two reasons — security and fairness. A key embedded in a public extension could be extracted by anyone who downloads it and used to spend the author's credits (it also breaks the GitHub/store security scanners). So Vizquo ships keyless by construction: you bring your own key (free at openrouter.ai), or use Ollama and need no key at all.

Does AI ever see my passwords or form values?

No — by construction. Payloads are bounded (text ≤ 200 characters) and redacted: input values, value/name/data-* attributes are stripped before anything can be sent, and the consent gate shows you the exact payload first.

What about Safari?

Safari support requires a native macOS build and the Apple Developer Program ($99/year). It's on the roadmap — vote for it and we'll notify you when it ships.

Why is install manual right now?

Browsers only allow one-click installs through their official stores, and Vizquo's store submissions are in progress. Until they're approved, the supported manual path is loading the ZIP (2 minutes). The page will switch to one-click buttons the moment each store approves.

Does it work on my phone?

Not yet — side-panel extensions don't exist on Android/iOS. Vizquo is a desktop-browser extension (Windows, macOS, Linux).

Can I uninstall or reset it?

Anytime. Remove it from chrome://extensions or about:addons, and Settings has a "Reset everything" that wipes all local data back to a fresh install.
