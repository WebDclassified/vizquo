Install

One-time setup, about a minute

Browsers restrict installs from outside their official stores — these are the safe, supported manual steps. After the stores approve Vizquo, this page will offer one-click buttons instead.

Chrome / Edge / Brave / Opera (Chromium)
  1. Download the ZIP for your browser above.
  2. Unzip it anywhere (right-click → Extract All). You'll get a folder named vizquo-0.10.1-chrome.
  3. Open chrome://extensions (or edge://extensions).
  4. Enable Developer mode (toggle, top-right).
  5. Click Load unpacked and select the unzipped folder.
  6. Pin Vizquo to your toolbar, open the side panel, and grant access to a page when prompted.
⚠️ Chrome will show a "Disable developer mode extensions" warning for any extension installed this way — that's expected and safe for manual installs. One-click installs arrive with the official store listing.
Firefox
  1. Download the Firefox ZIP above and unzip it.
  2. Open about:debugging#/runtime/this-firefox in Firefox.
  3. Click Load Temporary Add-on… and select the manifest.json inside the unzipped folder.
  4. Pin Vizquo and grant access to a page when prompted.
⚠️ Temporary add-ons reset when Firefox restarts — re-load it to keep using Vizquo. A permanent, one-click install comes with the AMO listing.

🔒 Local by default. Private by design.

No account, no tracking, no analytics — and zero network requests until you explicitly opt in. Scans, screenshots, and your library live only in your browser. Site access is granted per-site, on demand. AI is off by default and consent-gated. Full policy: Privacy Policy.
