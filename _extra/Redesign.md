# Vizquo — Definitive Landing Page Redesign Specification

**Version:** 2.0  
**Date:** 15 August 2026  
**Product:** Vizquo  
**Primary audience:** Designers, frontend developers, design engineers, design-system teams  
**Primary conversion:** Install the free browser extension  
**Design direction:** Instrumented Glass — premium material restraint + technical precision + interactive product proof

---

## 1. Executive Decision

The previous Vizquo landing-page design specification was a strong foundation. Its best ideas should remain:

- real product UI above the fold
- product-led storytelling
- restrained glassmorphism
- web instrumentation as Vizquo's visual identity
- `Inspect → Understand → Extract → Analyze → Experiment → Build`
- purposeful motion
- performance-safe 3D
- accessibility
- honest product claims
- no fake testimonials, metrics or customer logos

However, the previous document was still closer to a **premium feature showcase** than a fully optimized conversion system.

The redesign should move from:

```text
"Here are all the things Vizquo can do."
```

to:

```text
"Watch Vizquo solve the problem."
```

Current 2026 SaaS research repeatedly emphasizes clear one-sentence positioning, real product UI, interactive demonstrations, proof near claims, outcome-focused messaging and low-friction CTAs. citeturn0search0turn0search2turn0search4

### Final strategic direction

```text
CLARITY
  ↓
PRODUCT PROOF
  ↓
INTERACTION
  ↓
TRUST
  ↓
USE CASES
  ↓
FEATURE DEPTH
  ↓
INSTALL
```

The landing page should feel like **Vizquo itself inspecting a webpage**, not like a brochure describing Vizquo.

# 4. Major Problems With the Previous Design Direction

## Problem A — Too many features have equal visual importance

The previous specification gave separate weight to:

- Inspect
- Design System
- Assets
- Responsive
- Analyze
- Screenshot
- Live Edit
- Code
- AI
- Privacy
- Personas
- Social proof
- FAQ

This is comprehensive but can overwhelm visitors.

### New hierarchy

### Tier 1 — Why install Vizquo

```text
Inspect
Understand
Extract
```

### Tier 2 — Strong supporting proof

```text
Responsive
Analyze
Experiment
```

### Tier 3 — Power features

```text
Screenshot
Code
AI
Collections
Exports
```

The landing page should visually emphasize Tier 1.

---

## Problem B — "Glassmorphism" can become the product

Glass should support Vizquo's visual identity, not become the identity.

The final style is therefore called:

# Instrumented Glass

It combines:

```text
Apple-like material restraint
+
Linear-like precision
+
Vercel-like technical confidence
+
Framer-like motion
+
Figma-like visual creativity
+
Raycast-like instrumentation
+
Vizquo's inspection language
```

But Vizquo must remain visually distinct.

---

## Problem C — The feature list can become the story

The story must instead be:

```text
You see a webpage.
↓
You select something.
↓
Vizquo reveals how it is built.
↓
Vizquo finds the visual system.
↓
Vizquo extracts assets.
↓
Vizquo explains responsive behavior.
↓
You experiment.
↓
You build.
```

# 36. Glass Rules

Glass is a material.

Use it for:

- header
- product frame
- floating inspection panels
- active states
- selected states

Avoid using glass for:

- every section
- every paragraph
- every button
- every card

Three levels:

```text
Level 0 — background
Level 1 — subtle surface
Level 2 — elevated surface
Level 3 — active surface
```
